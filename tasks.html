The 8 Tasks

Each task is introduced on a specific day and builds on the skills developed in previous tasks. The difficulty increases as you progress.

1
Task 01 Beginner

Build the TechBridge Homepage

Day 1

Create the first version of the TechBridge website using HTML and CSS. Establish the foundation that the rest of the internship builds upon.

2
Task 02 Beginner

Build the Programs Experience

Day 4

Create a Programs experience that presents TechBridge's available learning programs. Show visitors what they can learn and why it matters.

3
Task 03 Beginner - Intermediate

Build the Internship Tasks Experience

Day 8

Create an interface that presents the TechBridge internship tasks and helps users understand the internship journey from start to finish.

4
Task 04 Intermediate

Build an Interactive Task Tracker

Day 11

Use JavaScript to make the internship task experience interactive and allow progress to be tracked. Bring your pages to life with dynamic behavior.

5
Task 05 Intermediate

Build the Intern Registration Experience

Day 15

Create a professional registration and onboarding interface for TechBridge interns. Design forms that are clear, accessible, and welcoming.

6
Task 06 Intermediate - Advanced

Build the Task Submission System

Day 19

Create an interface through which interns can prepare and submit their task work. Build a workflow that handles file uploads and submission status.

7
Task 07 Advanced

Build the Intern Dashboard

Day 22

Create a dashboard where an intern can view their profile, progress, tasks, and submissions. Pull together everything into one unified view.

8
Task 08 Advanced

Build the Complete TechBridge Internship Platform

Day 26

Combine the different components created during the internship into a complete TechBridge platform. This is your capstone project that brings everything together.
